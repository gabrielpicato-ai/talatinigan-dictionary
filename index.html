We are a three-person student team who designed and built Talatinigan, a simple English dictionary web application focused on clear definitions, useful word details, and an easy-to-use interface.

Open Dictionary Meet the Team

Learn a word without the clutter.

Talatinigan is a Dictionary Application that uses the Free Dictionary API. Its main goal is to let users search an English word and clearly display information returned by the API while demonstrating HTML, CSS, JavaScript, Fetch API, async/await, DOM manipulation, and error handling.

Look up

Search English words and retrieve dictionary information from a public API.

Understand

Read parts of speech, definitions, examples, synonyms, and pronunciation details when available.

Reliable UI

Input validation, loading feedback, empty states, and friendly API or network error messages.

Built with

Semantic HTML5, responsive CSS3, vanilla JavaScript, Fetch API with async/await, and GitHub-ready files.
