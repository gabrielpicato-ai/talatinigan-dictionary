PROJECT
Talatinigan is an English Dictionary Application. The user enters an English word and the application requests dictionary data from a public API, then dynamically displays the returned results.

API USED
Free Dictionary API
Documentation: https://freedictionaryapi.com/api/v1
Endpoint used:
https://freedictionaryapi.com/api/v1/entries/en/{word}

TECHNOLOGIES
- HTML5
- CSS3
- Vanilla JavaScript
- Fetch API
- async/await
- DOM manipulation

HOW TO RUN
1. Keep index.html, app.html, style.css, script.js, and the assets folder together.
2. Open index.html in a modern browser.
3. Click “Launch Talatinigan” to open the dictionary application.
4. Enter an English word and click Search.
5. An internet connection is required because the application retrieves live data from the Free Dictionary API.

RECOMMENDED LOCAL RUN
For the most consistent browser behavior, open the folder in Visual Studio Code and run index.html using Live Server.
